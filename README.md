# Machine Learning

A collection of lab codes and practice implementations written while learning Machine Learning. Covers time series, regression, classification, ensemble methods, clustering, dimensionality reduction, deep learning (CNN), and SVMs — implemented in Jupyter Notebooks.

## 📁 Repository Structure

| Folder                           | Description                                                                 |
| -------------------------------- | --------------------------------------------------------------------------- |
| `Lab0_Familiarization`           | Getting familiar with the Python/ML environment and tooling                 |
| `Lab1_Time_Series_Data`          | Time series data analysis practice                                          |
| `Lab2_Regression`                | Regression models practice                                                  |
| `Lab3_Grad._Descent_Logistic`    | Gradient descent and logistic regression from scratch                       |
| `Lab4_DecisionTree_RandomForest` | Decision Tree and Random Forest classifiers                                 |
| `Lab5_Clustering`                | Clustering algorithms practice                                              |
| `Lab6_PCA_Implementation`        | Principal Component Analysis on the Iris dataset                            |
| `Lab7_CNN`                       | CNN implementation, plus a variant using batch normalization                |
| `ANN`                            | Artificial Neural Network practice code                                     |
| `SVM`                            | Support Vector Machine practice code                                        |
| `datasets`                       | Shared datasets used across labs (Iris, diabetes, placement, online retail) |

## 🛠️ Tech Stack

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Core Libraries:** NumPy, Pandas, Scikit-learn, Matplotlib, TensorFlow/Keras (for ANN/CNN)

## 🚀 Getting Started

```bash
git clone https://github.com/adhikari-arpan/Machine_Learning.git
cd Machine_Learning
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook
```

## 📌 Notes

- Each folder is self-contained with its own notebook(s).
- `datasets/` holds shared data files (Iris, diabetes, placement, online retail) referenced across labs.
- This repo is a personal practice log and is updated as I learn new ML concepts and algorithms.
